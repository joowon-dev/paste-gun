# 붙여넣기 총

복사한 글자가 총알이 됩니다. `⌘V`(윈도우 `Ctrl+V`)를 누르면 총이 글자 커서로 날아와 한 글자씩 쏴서 붙여넣습니다.

- **받는 곳**: https://joowonkoh.com/playground/paste-gun
- 총 네 자루 — 권총(글 하나씩) · 기관총(탄창 전체를 Tab 으로 이어서) · 샷건(뭉텅이로) · 저격총(`⌥⇧1~9` 로 골라서 한 방)
- 여러 개를 복사해 두면 복사한 순서대로 나갑니다. 자주 쓰는 글은 탄창으로 저장해 둘 수 있습니다
- 쏠 글이 없거나 그림·파일을 복사했을 때는 평소 붙여넣기 그대로입니다. 비밀번호 관리자가 복사한 것은 줍지 않습니다
- 단축키는 무기고(`⌥⇧A` / `Alt+Shift+A`)에서 바꿉니다
- 맥 (Swift + WKWebView) · 윈도우 (.NET + WebView2)

## 설치와 제거

| | 설치 | 제거 |
|---|---|---|
| 맥 | dmg 를 열어 Applications 로 끌어 넣고, 처음 켤 때 **손쉬운 사용** 권한을 줍니다 (다른 앱에 키를 보내야 해서) | 메뉴바 아이콘 → 「붙여넣기 총 제거…」 — 앱·저장한 탄창·로그인 항목·권한을 한 번에 치웁니다 |
| 윈도우 | `PasteGun-win-Setup.exe` 를 실행합니다. .NET 9 데스크톱 런타임이 없으면 설치본이 받아서 깝니다 | 「설정 → 앱」 또는 트레이 아이콘 → 「붙여넣기 총 제거…」 |

새 버전이 나오면 메뉴에 「새 버전 설치」가 생깁니다. 누르면 받아서 갈아 끼우고 다시 뜹니다.

## 만들기

```bash
npm install
npm start          # 맥에서 빌드하고 띄우기
npm test
npm run build:win  # 윈도우 셸 컴파일 (맥에서도 된다)
```

릴리스는 태그(`v*`)를 밀면 CI 가 만듭니다. 맥 배포본은 `./mac/notarize.sh` 로 공증한 것으로 덮어씁니다.
윈도우 셸은 CI 가 설치본을 실제 윈도우 러너에 깔고 `Ctrl+V` 로 쏴 본 뒤 제거까지 해 봅니다(`windows/smoke.ps1`).
